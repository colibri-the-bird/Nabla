# Архивирование чатов

Для важных обсуждений сохраняйте экспорт в Markdown:

```text
chats/
  YYYY-MM-DD-короткое-название.md
```

В начале каждого файла желательно указывать:

- дату;
- исходное название чата;
- сервис: ChatGPT или Codex;
- краткое решение или результат;
- связанные файлы и коммиты;
- статус: черновик, утверждено или устарело.

Не включайте секреты, токены и персональные данные, особенно если репозиторий может стать публичным. Экспорт чата является исторической записью и не должен переопределять нормативные спецификации.
